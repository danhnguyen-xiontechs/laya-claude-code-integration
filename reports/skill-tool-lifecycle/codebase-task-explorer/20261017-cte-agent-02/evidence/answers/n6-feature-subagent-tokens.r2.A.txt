Caveats from reading the code:
- `sumOrNull` in build_tool_report.mjs treats a missing value as 0 once any value is present. A repetition with no usage therefore lowers that case's mean silently, and a case with no usage adds 0 to the arm totals. Only the paired-token comparison is guarded by excluding unpaired cases.
- subagent_usage.mjs does not sum agents spawned by a case agent. It passes `--no-subagents`, and transcript_usage looks for `<file>/subagents`, which does not exist for a flat `agent-<id>.jsonl`. A nested transcript whose prompt names the same work dir makes the case null; otherwise its tokens are left out.
