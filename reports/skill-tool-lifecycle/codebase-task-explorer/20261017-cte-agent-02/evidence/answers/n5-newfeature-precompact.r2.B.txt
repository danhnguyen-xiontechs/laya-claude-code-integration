Notes for the implementer:
- The existing guard in fast-compact.ts returns the built-in path for `auto` triggers and subagents (`agentId`). A summary hook has to decide deliberately whether to cover auto-compaction, and should skip `precompute`, which would otherwise write duplicate files.
- Errors should fall back to `next(event)` unchanged, as fast-compact does, so a failed summary never blocks compaction.
- A classic PreCompact event exists in the types, but no repo plugin uses it.
