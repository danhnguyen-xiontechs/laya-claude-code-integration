Key findings for the design:
- Use the function-hook route `on('session.compact', ...)`, the same as the existing plugins. The repo's plugin hooks.json files only list modules, so the classic PreCompact settings hook is not the pattern used here.
- Pass through with `return next(event)` so the built-in summary still runs. The new hook must not alter the result.
- Skip trigger `precompute`. The types describe it as a dispatch that installs nothing, so it should not write a summary file.
- The engine offers a tool-less completion over the session's own transcript (around line 2172 of claude-code.d.ts). That is one option if the summary should be model-written. A deterministic summary built from `event.messages` (user prompts, tool names, turn count) needs no model call.
