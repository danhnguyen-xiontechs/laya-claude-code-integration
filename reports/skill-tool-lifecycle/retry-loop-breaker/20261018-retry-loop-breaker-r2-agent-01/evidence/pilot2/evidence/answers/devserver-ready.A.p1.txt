- This Windows host has no /run/devcerts directory (checked), so stage 5 waits forever ("waiting for cert-agent ... (2)" in the log).
- test/server.test.js allows only 1500 ms, which is shorter than a fresh bootstrap (NOTES.md says so). That is why the first runs failed. The failure after that is the missing agent.

- package.json has no build script, so no build was run.
