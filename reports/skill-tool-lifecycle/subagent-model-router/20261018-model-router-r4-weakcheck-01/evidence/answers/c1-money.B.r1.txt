Created src/money.js in the a1 work folder with an exported parseAmount(text): it validates against /^([+-]?)(\d+)(?:\.(\d{1,2}))?$/ (after String()), builds cents as an integer digit string (no float math), returns 0 rather than -0, and throws RangeError("bad amount: " + input) otherwise. `node check.mjs` prints PASS, and extra edge cases (1.234, 1., .5, empty, letters, 1e3, 1,000, spaces, lone sign) throw the correct error.
