Created src/ranges.js in the work folder with mergeRanges(ranges): it validates every pair first (throws RangeError "bad range: " + JSON.stringify(pair) if start > end), copies and sorts the pairs by start, merges when next start <= current end + 1, and returns fresh arrays without mutating the input. `node check.mjs` prints PASS. The module uses CommonJS `exports.mergeRanges`, since the folder has no package.json and check.mjs imports it fine that way.
