# fast-compact

Opt-in, deterministic, verbatim compaction for Claude Code. `/fast-compact` previews what would
be cut and arms the **next manual `/compact`** (once, within 15 minutes) to keep the conversation
verbatim instead of summarizing it: old tool outputs and bulky tool inputs are trimmed by fixed
rules per tool, while every message, every tool call and all user/assistant text stay in place.
No model call, no API key. Auto-compaction and un-armed `/compact` keep the built-in summary.

- `hooks/fast-compact.ts`: the rules (`planCompaction`) and the `session.compact` function hook.
  The hook is inert unless armed. It falls back to the built-in summary below 25% reduction or
  on any error, including a `.catch` for a failed or overrun hook.
- `skills/fast-compact/SKILL.md`: the switch. It previews, arms, and tells you to type `/compact`.
- `scripts/preview.ts`: runs the same rules over a session transcript; `--arm`, `--disarm`, `--json`.

## Install

Function hooks are an early-access Claude Code feature (2.1.274+), so enable them where Claude
Code runs, for example in `~/.claude/settings.json`:

```json
{ "env": { "CLAUDE_CODE_ENABLE_FUNCTION_HOOKS": "1" } }
```

Then add this folder as a marketplace and install it:

```sh
claude plugin marketplace add <path-to>/fast-compact
claude plugin install fast-compact@fast-compact
```

Or try it without installing: `claude --plugin-dir <path-to>/fast-compact`.

## Use

```
/fast-compact            preview + arm, then type /compact
/fast-compact preview    preview only
/fast-compact off        disarm
```

From a shell: `node scripts/preview.ts [--session <file.jsonl>] [--arm]`.

## Why these rules (measured 2026-10-13)

This started as a study of [tamaratran/fast-jev-compaction](https://github.com/tamaratran/fast-jev-compaction),
where TypeSafe Jev decides which tool calls to drop. On 4 real sessions, each cut at 60%, with
158 calls labelled in hindsight by Haiku 5.5:

| | Jev (result heads in state) | these rules |
|---|---|---|
| characters removed | 67–76% | 47–58% |
| still-needed calls kept | 0 / 38 | 38 / 38 |
| still-needed outputs kept whole | 0 / 6 | 2 / 6, the other 4 as head + tail (all `grep` runs, cheap to re-run)* |
| cost | ~2 s and an API call per compaction | none |

\*Measured with a 500-char shell threshold; the shipped 1200 keeps two of those four whole.

Jev's probabilities never cleared its 0.5 threshold, so it dropped everything, and its ranking did
not beat the "keep Edit/Write calls" rule. After the trimming, what is left is mostly
assistant text and Write/Edit inputs, which is why the inputs are trimmed too. Caveats: one
project's sessions, model-made labels, characters rather than tokens.
